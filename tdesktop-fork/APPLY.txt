【本机编译前置：Visual Studio 组件】
必须勾选 C++ ATL，否则 prepare 会在 breakpad 阶段挂掉：
  D:\Libraries\win64\breakpad\src\common\windows\dia_util.cc(31,10):
  error C1083: Cannot open include file: 'atlbase.h'
在 VS Installer → 单个组件 里搜 ATL，勾：
  → C++ ATL for latest v143 build tools (x86 & x64)
（CI 上由 apply.py 自动补装，本机需要手动勾。）

这台 Mac 编不出 Windows 的 Telegram.exe（物理平台边界，需 VS + Win SDK）。
请在 Windows 上按配套手册执行：
  → tdesktop-fork/构建手册-在Windows上编译气泡译文版.md
一键驱动脚本：
  → tdesktop-fork/build-on-windows.bat   （fresh 模式：clone→补丁→prepare→configure→编译 全自动）
手动 apply：python apply.py D:\TBuild\tdesktop

编出来后替换：HelloPix-Telegram\Telegram\Telegram.exe
登录后启动器会往各实例 -workdir 写 hello-pix-bridge.json，魔改电报读桥接在气泡出 [译文]。

【桥接契约】hello-pix-bridge.json 放在 -workdir 根目录（与 tdata/ 同级）
  apiBase / deviceId / cookies / engine / lang / transRecv / transSend / transGroup
  读取方式：cWorkingDir() + "hello-pix-bridge.json"
  （cWorkingDir() 由 settings.h 的 DeclareSetting(QString, WorkingDir) 提供，
    实际值 = 启动参数 -workdir 的绝对路径 + '/'，已在 core/launcher.cpp 核实）
